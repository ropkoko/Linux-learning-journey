1️⃣ Installing Linux

Linux is an operating system widely used in servers, cloud computing, and development environments.

For my learning journey, I installed Ubuntu Linux, one of the most beginner-friendly Linux distributions.
Key Things Learned

    How to download Ubuntu
    How to install Ubuntu on a machine / virtual environment
    Understanding that Linux comes in many distributions
    Why Ubuntu is popular for beginners and professionals

Why It Matters

Installing Linux is the first step toward learning system administration, cloud computing, and DevOps skills.
2️⃣ Desktop Environment

The Desktop Environment is the graphical interface of Linux that allows users to interact with the system using windows, icons, menus, and panels.

Ubuntu commonly uses GNOME Desktop Environment.
Key Things Learned

    Logging in to Ubuntu
    Navigating the desktop
    Opening applications
    Managing windows
    Accessing system settings

Why It Matters

The desktop environment helps users interact with Linux visually before moving deeper into command-line usage.
3️⃣ Terminal and Shell

The Terminal is an application where commands are typed.

The Shell is the program that reads commands, interprets them, and communicates with the operating system.

Ubuntu commonly uses Bash as the default shell.
Commands Practiced

pwd
ls
cd
clear 

### Key Things Learned

Opening terminal
Running commands
Understanding command output
Navigating directories using terminal

##Why It Matters

The terminal is one of the most powerful tools in Linux and is heavily used in servers and cloud environments.

##Key Things Learned

##5️⃣ Working with Files

Commands Practiced

~rm oldnotes.txt

##Key Things Learned

~Creating files
~Copying files
~Renaming files
~Moving files
~Deleting files

Why It Matters

Managing files efficiently is a daily Linux skill used in administration and development.

##6️⃣ Working with File Content

Files often contain text, code, or configuration data.

Commands Practiced

~tail notes.txt

##Key Things Learned

Viewing file content
Editing files in terminal
Reading first lines of files

##Why It Matters

Understanding file content is important for reading logs, editing configs, and managing scripts.

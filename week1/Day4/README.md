# 📘 What Is a Shell Script?

A **shell script** is a text file containing a sequence of Linux commands that are executed automatically by the shell.

Instead of manually typing commands one by one, you place them inside a file and run the script.

## Example:

```bash

echo "Hello World"

📘 Why Shell Scripting Is Important

Shell scripting is used to:
